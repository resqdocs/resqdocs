# ResQDocs 1.9.0

Version 1.9.0 bringt zwei Funktionen für die Schlaganfall-Erhebung und macht das Teilen von Vorlagen einfacher.

## Added
- FAST4D und LAMS als Funktionen: Befunde im Eingabeblatt antippen, das Ergebnis steht als eine Zeile im Protokolltext. Jeder Befund ist kurz erklärt.
- Funktionen können in der Vorlage auf „nicht erhoben“ starten und kommen erst ins Protokoll, wenn sie eingeschaltet werden.
- Ein angetippter Vorlagen-Link öffnet die App und fragt vor dem Import nach. Auf iPhone und iPad lässt sich eine Vorlagen-Datei über das Teilen-Menü an ResQDocs schicken.
- Auswahllisten bieten „individuell“ als Eintrag an; das Textfeld startet mit der aktuellen Auswahl.
- Alte Sicherungen lassen sich auf Wunsch nach einer selbst gewählten Frist automatisch löschen.

## Changed
- Die Listen der Sicherungen zeigen zuerst die neuesten Einträge.
- Aktualisierte Abhängigkeiten, u. a. Capacitor 8.6.2, Vue 3.5.45 und Vite 8.3.8.

## Fixed
- Beim Import mit „Überschreiben“ bleibt die Vorlage an ihrem Platz und bleibt Standard-Vorlage.
- Eine Mehrfachauswahl bleibt offen, wenn der Standardwert als Erstes abgewählt wird.
