# ResQDocs 2.1.1

Version 2.1.1 macht Kurzlinks einfacher weiterzugeben, hält die Anleitung immer griffbereit und behebt Fehler beim Lückentext und in Fenstern.

## Changed
- Kurzlink: Beim Teilen steht nur noch der Code (z. B. VLm6X) groß im Feld, „Kopieren“ kopiert weiter den ganzen Link. Zum Empfangen genügt der Code allein; resq.li/… mit oder ohne https:// und der lange Link gehen ebenso. Groß- und Kleinschreibung zählen.
- Anleitung: Das ? oben rechts öffnet Einführung und Anleitung. Oben links führt „Anleitung“ auf jeder Seite der Einführung zur Anleitung auf resqdocs.app.
- Online-Editor: Der Lückentext heißt und zeigt sich wie in der App, mit eigenem Symbol ¶.

## Fixed
- Lückentext: Blendet eine Antwort weitere Lücken ein, kommen sie beim „Ausfüllen“ direkt als Nächstes dran, und der Zähler zählt sie mit. Vorher endete der Durchgang davor.
- Unter der Knopfzeile eines Fensters (z. B. „Schließen“ im Fenster „Daten“) scheint beim Scrollen kein Inhalt mehr durch.
- Ein abgetippter Kurzlink oder Code meldet klar, wenn er unvollständig ist oder die Schreibweise nicht stimmt.
