# ResQDocs 1.5.0

Version 1.5.0 lässt Felder und Abschnitte auf „nicht erhoben“ starten, schützt besser vor Datenverlust und korrigiert den Regler für die Tippgeschwindigkeit.

## Added
- **Startet auf „nicht erhoben“:** Felder und Abschnitte können in der Vorlage so eingestellt werden, dass sie im Einsatz leer starten und erst ins Protokoll kommen, wenn du sie einschaltest.

## Fixed
- Stärkerer Schutz vor Datenverlust: Ein laufender Einsatz wird nicht verworfen, wenn die Bibliothek nicht lesbar ist, und Speicherfehler werden angezeigt statt verschluckt.
- Beim Bearbeiten von Bausteinen geht kein Text mehr verloren: Speichern ist vom Schließen getrennt.
- Der Regler für die Tippgeschwindigkeit lief verkehrt herum und zeigt keine Millisekunden mehr; der Testtext folgt der eingestellten Geschwindigkeit.
